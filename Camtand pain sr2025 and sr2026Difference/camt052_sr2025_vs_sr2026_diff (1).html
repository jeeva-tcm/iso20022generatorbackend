Key areas to update in your ISO 20022 validator (camt.052)

📋 Code lists — refresh ExternalPurpose1Code, ExternalPersonIdentification1Code, CBPR+ local instrument codes to SR2026 versions
🏛️ Postal address — add structured-address usage-rule check (TwnNm + Ctry minimum); flag unstructured-only usage
🆔 LEI fields — add support for new LEI tag under DbtrAgt and CdtrAgt in related agents
⚠️ Mandatory checks — TtlNetNtryAmt mandatory when parent present; CdtDbtInd mandatory in TtlNtries
🔁 Mutual exclusion — Ustrd remittance must not co-exist with Strd in the same TxDtls
💶 Tax block — new TxDtls/Tax parser needed; add TaxDt, TaxTp, TaxAmt field support
